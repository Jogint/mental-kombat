## Como trabalhar no projeto

* Clone o repositório na sua máquina (abre o vscode e clica em clone repository se for mais fácil).
* Preferencialmente, salve na pasta GameMakerProjects, que fica na pasta do seu usuário do computador por padrão
* Abra o arquivo yyp no seu GameMaker
* Se divirta adicionando novas coisas no projeto!
